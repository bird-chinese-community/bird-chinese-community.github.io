`@birdcc/intel` 包含一份 AS 名称、AS 类别与国家代码的快照。语言服务器用它提供 AS 号补全、悬停提示与内嵌提示。快照是包中的 `db/asn-db.bin.gz` 文件。服务器在启动时从磁盘读取它，不会为 ASN 数据发起网络请求。

`@birdcc/intel` 1.0.0 包含 2026-11-02 的数据库更新：122,819 条记录，文件大小 1,608,171 字节。服务器启动时在日志中输出记录数：

```text
[intel] ASN database loaded: 122819 records
```

## 数据来源 [#source]

数据来自 [BGP.Tools-OpenDB](https://github.com/Alice39s/BGP.Tools-OpenDB) 仓库 `auto-update` 分支上的 `asns/asns.csv`。该仓库每天从 bgp.tools 更新 ASN 列表。CSV 的列为 `asn`、`name`、`class` 与 `cc`。

`@birdcc/intel` 的构建脚本 `scripts/build-db.ts` 按以下步骤转换 CSV：

1. 去掉每个 ASN 的 `AS` 前缀，丢弃 ASN 不是数字的行。
2. 把类别 `Unknown` 存为空字符串。
3. 按 ASN 排序。
4. 把四个并列数组 `[asns, names, classes, ccs]` 编码为 MessagePack，再以 gzip 9 级压缩。

## 数据库内容 [#content]

每次查询返回一条记录：

| 字段   | 内容                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| `asn`  | AS 号，0 到 4294967295。                                                               |
| `name` | AS 名称。                                                                              |
| `cls`  | bgp.tools 的类别，例如 `Eyeball`、`Content`、`Carrier` 或 `T1`。类别未知时为空字符串。 |
| `cc`   | 两个字母的国家代码，或空字符串。                                                       |

保留 AS 号来自包内的一张表，不来自 CSV。它们的记录为 `cls: "Reserved"`、`cc: "ZZ"`，`name` 为定义它们的文档：

| AS 号                                            | `name`          |
| ------------------------------------------------ | --------------- |
| `0`                                              | `RFC 7607`      |
| `112`                                            | `AS112 Project` |
| `23456`                                          | `RFC 4893`      |
| `64496` 到 `64511`，`65536` 到 `131071`          | `RFC 5398`      |
| `64512` 到 `65534`，`4200000000` 到 `4294967294` | `RFC 6996`      |
| `65535`，`4294967295`                            | `RFC 7300`      |

建立查询索引之前，加载器在以下情况下拒绝数据库文件：

- 解压后超过 32 MiB，或者内容为空。
- 记录超过 1,000,000 条，或者四个数组长度不同。
- ASN 不是 0 到 4294967295 之间严格递增的整数。
- 某个国家代码既不为空，也不是两个大写字母。

## 更新 [#updates]

BIRD-LSP 的 [`intel-asn-update.yml`](https://github.com/bird-chinese-community/BIRD-LSP/blob/main/.github/workflows/intel-asn-update.yml) 工作流每周一 04:00 UTC 重新构建数据库：

1. 在 `packages/@birdcc/intel` 中运行 `pnpm build:db`，下载当前的 CSV。
2. `db/asn-db.bin.gz` 不存在或小于 100,000 字节时停止。
3. 文件有变化时，为 `@birdcc/intel` 添加一条 patch 版本的发布说明。
4. 从 `feat/weekly-asn-database` 分支创建或更新拉取请求 `chore(intel): Update ASN database`。

合并后的更新随 `@birdcc/intel` 的下一个 patch 版本发布。已安装的包会一直使用它自带的快照，直到你更新这个包。BIRD2 LSP 扩展内置了服务器和数据库，所以新的快照随新的扩展版本一起提供。

要自己构建这个文件，在 [BIRD-LSP](https://github.com/bird-chinese-community/BIRD-LSP) 的克隆中运行 `pnpm install` 之后，执行：

```sh
pnpm --filter @birdcc/intel build:db
pnpm --filter @birdcc/intel build:db -- --csv /path/to/asns.csv
```

第一条命令下载 CSV。第二条命令读取本地副本，相对路径基于 `packages/@birdcc/intel` 解析。两条命令都写出 `packages/@birdcc/intel/db/asn-db.bin.gz`。

## 语言服务器中的用法 [#features]

服务器把以下位置的数字当作 AS 号：

- `local as <n>` 与 `neighbor <address> as <n>`。
- `bgp_path.prepend(<n>)`、`bgp_path.delete(<n>)`，以及 `bgp_path ~ [ ... ]` 中的每个数字。
- `community.add((<n>, ...))` 与 `large_community.add((<n>, ...))` 的第一个数字（带或不带 `bgp_` 前缀），以及 `(<n>, <m>) ~ bgp_community` 的第一个数字。
- `NAME` 中含有以下划线分隔的 `ASN` 或 `COMMUNITY` 单词时（例如 `MY_ASN`）的 `define <NAME> = <n>`。

在 community 与 `define` 位置，小于 100 的数字会被忽略，42 除外。`community.add` 与 `~ bgp_community` 位置还会忽略 65535。悬停提示与内嵌提示跳过字符串中以及 `#` 或 `//` 之后的文本。在注释中输入 `# AS<digits>` 后也会触发补全。

| 功能     | 内容                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 补全     | 最多 10 个以已输入数字开头的 AS 号，完全匹配的排在最前。详情为 `<flag> AS<n> · <name>`。 |
| 悬停提示 | 一张表，包含 AS 名称和 ASN，存在时还包含国家和类别，以及指向 BGP.Tools-OpenDB 的链接。   |
| 内嵌提示 | 数字之后显示 `<flag> AS<n>`。超过六位的 ASN 显示前六位加 `..`，例如 `AS420000..`。       |

`<flag>` 是 `cc` 对应的区域指示符旗帜；保留 AS 号显示白旗；`cc` 为空时不显示旗帜。只有数据库或保留表中存在的 AS 号才显示内嵌提示。

## 关闭这些功能 [#settings]

每项功能都有一个设置，默认值都是 `true`。

| 语言服务器设置     | VS Code 设置                 | 设为 `false` 的效果                  |
| ------------------ | ---------------------------- | ------------------------------------ |
| `intel.enabled`    | `bird2-lsp.intel.enabled`    | 关闭 AS 号补全、悬停提示与内嵌提示。 |
| `intel.completion` | `bird2-lsp.intel.completion` | 关闭 AS 号补全。                     |
| `intel.hover`      | `bird2-lsp.intel.hover`      | 关闭 AS 号悬停提示。                 |
| `intel.inlayHints` | `bird2-lsp.intel.inlayHints` | 关闭 AS 号内嵌提示。                 |

在 VS Code 中：

```json title="settings.json"
{
  "bird2-lsp.intel.inlayHints": false
}
```

其他客户端在 `initializationOptions.birdcc` 或 `workspace/configuration` 的 `bird2-lsp` 节中发送设置。例如在 Neovim 中：

```lua
vim.lsp.config("birdcc", {
  settings = {
    ["bird2-lsp"] = {
      intel = { enabled = false },
    },
  },
})
```

[语言服务器设置](./reference/language-server.mdx#settings)列出其他键。

## 使用其他数据库文件 [#replace]

`birdcc lsp` 始终加载已安装的 `@birdcc/intel` 中的数据库。要加载其他文件，用 `@birdcc/lsp` 的 `startLspServer` 和 `asnDbPath` 选项启动服务器：

```ts title="server.mjs"
import { startLspServer } from "@birdcc/lsp";

startLspServer({ asnDbPath: "/srv/asn/asn-db.bin.gz" });
```

```sh
node server.mjs --stdio
```

- 文件格式必须与 `scripts/build-db.ts` 写出的格式相同。构建命令见[更新](#updates)。
- 相对的 `asnDbPath` 基于服务器进程的工作目录解析，请使用绝对路径。
- 把编辑器的服务器命令设为这条命令。在 VS Code 中对应的设置是 `bird2-lsp.serverPath`，例如 `["node", "/srv/asn/server.mjs", "--stdio"]`。
- `startLspServer({ disableAsnIntel: true })` 启动服务器时不加载 ASN 数据库。

文件无法加载时，服务器继续运行，AS 号功能不返回任何结果，保留 AS 号也一样。日志给出原因：

```text
[intel] ASN database unavailable: {"code":"missing","message":"ENOENT: no such file or directory, open '/srv/asn/asn-db.bin.gz'","dbPath":"/srv/asn/asn-db.bin.gz","version":{"packageVersion":"1.0.0"}}
```

`code` 为 `missing`、`read`、`decompress`、`decode` 或 `schema`。

## 在代码中查询数据库 [#api]

```sh
npm install @birdcc/intel
```

```ts
import { createAsnIntel } from "@birdcc/intel";

const intel = createAsnIntel();
if (!intel.available) {
  throw new Error(`ASN database unavailable: ${intel.failure?.code}`);
}

console.log(intel.exactLookup(13335));
console.log(intel.prefixSearch("1333", 3).map((entry) => entry.asn));
console.log(intel.exactLookup(65001));
```

```text
{ asn: 13335, name: 'Cloudflare, Inc.', cls: 'Content', cc: 'US' }
[ 1333, 13330, 133300 ]
{ asn: 65001, name: 'RFC 6996', cls: 'Reserved', cc: 'ZZ' }
```

- `createAsnIntel(dbPath)` 加载其他文件。文件无法加载时，它返回 `available: false`、空的查询结果和一个 `failure` 对象，不会抛出异常。
- `prefixSearch(prefix, limit)` 按每个 ASN 的十进制形式匹配，默认上限为 10。完全匹配的排在最前，其余结果按字典序排列。
- 查询结果取决于已安装包中的快照。
